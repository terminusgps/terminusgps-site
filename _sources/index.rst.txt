terminusgps-site documentation
==============================

==================================
How the documentation is organized
==================================

Terminus GPS documentation is organized following the `Diátaxis <https://diataxis.fr/>`_ approach, separated into four types:

* :doc:`Tutorials <tutorials/index>`: Tutorials take you by the hand through a series of steps to use the Terminus GPS software. Start here if you're new to Terminus GPS.
* :doc:`Topic Guides <topics/index>`: Topic guides discuss key topics and concepts at a fairly high level and provide useful background information and explanation.
* :doc:`Reference Guides <references/index>`: Reference guides contain technical references for APIs and other aspects of Terminus GPS machinery. They describe how it works and how to use it but assume that you have a basic understanding of key concepts.
* :doc:`How-To Guides <how_tos/index>`: How-to guides are recipes. They guide you through steps involved in addressing key problems and use-cases. They are more advanced than tutorials and assume some knowledge of how Terminus GPS works.
